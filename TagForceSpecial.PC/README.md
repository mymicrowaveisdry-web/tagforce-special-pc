# PC application host

[MonoGame GUI](Presentation.md) provides a 480 × 272 supported duel, native setup/deck editor and private-information views; original artwork/font/audio decoding and PSP visual matching remain unfinished.

Run `dotnet run --project TagForceSpecial.PC`. Every normal launch opens the WPF importer workbench; Play Game validates the active import and starts the game. The workbench imports the exact English v2.1 ISO or extracted folder and prepared recipes, including title artwork; it automatically installs local pinned PSP fonts and includes prepared recipes unless **Include recipes** is unchecked. New Game/Continue reach the original Main Menu using a native profile; Options, Save Data and the Deck Menu submenu work there; Deck Edit opens its original core screen (list, tabs, moves, exit; the Trunk is the PC's supported cards) and Recipe Viewer browses private source recipes with sorting and previews from the imported library (or `--recipe-reference <private-root>`) (read-only, Character coverage partial, returned deck selection unverified); Partner Deck Edit shows a PC notice; the Database submenu opens the Card Album (binder, page turns, Page Jump and card detail; it needs a private captured binder package, which the import installs from a local album-reference folder, or `--album-reference <dir>`) and shows a PC notice on its other rows; Free Duel opens its original settings screen (Normal Duel, Single, standard rules or LP 4000, music; Tag Duel, CPU Spectator, Match and time limits show a PC notice) and Next opens its VERSUS screen, where any of the original 192 characters can be chosen in its character picker (or at random) and plays a labelled PC deck, and the player uses the current deck; both deck pickers list the original decks greyed beside the PC deck. Start Duel uses rock-paper-scissors to decide turn order. The PC result panel offers a rematch or a return to the Main Menu with an optional profile save. Other rows show an unavailable notice. F12 opens PC tools; Back there returns to the workbench, including deck editing and supported duels. Original PSP save import remains unfinished; Tag Force 6 transfer is deliberately unsupported. Controls: arrows or WASD/D-pad, F1/controller Start, Enter/A, Tab/Y and Escape/B by default, rebindable under PC tools > Controls (saved with preferences); the mouse works on the front-end screens (hover focuses, left click selects, right click backs out, wheel scrolls); see the [opponent contract](../TagForceSpecial.AI/Contract.md).

Presentation check: `dotnet run --project TagForceSpecial.PC -- --presentation-smoke --data-root <validated-private-root> --presentation-trace <new-private.json>` replays 5 cycles of every observed Continue/New Game, Main Menu, Options, Deck Menu, Free Duel settings, Database and Card Album route with fixed frames (`--deck-menu-frame <n>` fixes the submenu's own frame); add `--capture-flow <new-private-dir>` to save each state. `--data-root <private-copy> --presentation-realtime <new-private-dir>` walks New Game to the Main Menu and back at normal speed. Edit [GumProject.gumx](UI/Gum/GumProject.gumx).

## Private data and recovery

- Data defaults to `%LOCALAPPDATA%/TagForceSpecial`; `--data-root <directory>` isolates testing.
- The bundled [WPF workbench](../docs/importer/USER_GUIDE.md) replaces the in-game importer and offers import, maintenance and asset/evidence inspection.
- Deck revisions remain separate from caches; invalid drafts can be saved but cannot launch.

Original sources stay read-only. Assets/catalogs remain private and are not bundled or downloaded; resource status lists remaining art/font/audio gaps.
